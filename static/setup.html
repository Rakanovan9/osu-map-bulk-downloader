First-Time Setup

Configure the application below. This tool requires your osu! OAuth credentials and your Songs directory.

How to obtain credentials:
  1. Visit osu.ppy.sh Account Settings.
  2. Scroll to OAuth and click "New OAuth Application".
  3. Enter a name, leave Redirect URI blank.
  4. Copy the Client ID and Client Secret generated.
Step 1: osu! API Credentials
Step 2: Local Songs Directory
Usually located at %LOCALAPPDATA%\osu!\Songs
